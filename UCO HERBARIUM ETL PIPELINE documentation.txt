WHAT THIS PIPELINE DOES
--------------------------------------------------------------------------------

This pipeline takes a raw specimen occurrence file downloaded from the TORCH
Portal and produces two outputs ready for use in ArcGIS and the UCO Herbarium
StoryMap: a cleaned specimen dataset and a county-level summary shapefile for
choropleth mapping. It performs the following steps automatically each time
it is run:

  1. Fills in missing coordinates using authoritative county centroids
  2. Checks that each specimen's coordinates fall within its listed county
  3. Removes records with coordinates outside Oklahoma
  4. Matches specimens against the Oklahoma State Tracking List to add
     conservation ranking information
  5. Removes sensitive species records (orchids and Horse Crippler Cactus)
     from the public-facing dataset
  6. Aggregates specimen and conservation ranking counts to the county level
     and exports a county shapefile for choropleth mapping
  7. Exports the cleaned dataset and a set of log files for review


================================================================================

BEFORE YOU RUN THE PIPELINE
--------------------------------------------------------------------------------

Step 1 — Download a fresh occurrence file from the TORCH Portal
  - Go to: https://portal.torcherbaria.org/
  - Export the UCO collection in Darwin Core CSV format
  - Save the file as: CSUoccurrences.csv

Step 2 — Replace the old file
  - Navigate to the pipeline folder on your computer
  - Open the "data" subfolder
  - Replace the existing CSUoccurrences.csv with your new download
  - Keep the filename exactly the same: CSUoccurrences.csv

Step 3 — Do not move or rename any other files
  - okCounties.geojson and okStateTracking.csv should remain in the data folder
  - These files do not need to be replaced


================================================================================

HOW TO RUN THE PIPELINE
--------------------------------------------------------------------------------

  1. Open ArcGIS Pro
  2. Open the Python window or launch the arcgispro-py3 environment
  3. Navigate to the pipeline folder
  4. Run: UCO_Herbarium_ETL_Pipeline.py
  5. The pipeline will print progress messages as it runs
  6. When complete, you will see: "ETL pipeline complete!"


================================================================================

UNDERSTANDING THE OUTPUT
--------------------------------------------------------------------------------

CLEANED SPECIMEN DATASET
  Location: data/cleanedCSUoccurrences.csv

  This is the primary specimen output. It contains all validated Oklahoma
  specimens with sensitive species removed. This file is ready for import
  into ArcGIS and publication to ArcGIS Online as a point feature layer.

  New fields added by the pipeline:

  geographicPrecision
    Describes the reliability of each record's coordinates:
    - PRECISE              = coordinates were verified by a georeferencer
    - ASSIGNED CENTROID    = no coordinates were provided; the county center
                                point was used as a placeholder
    - PRECISION UNVERIFIED = coordinates exist but `georeferenceVerificationStatus` 
                                field held null or 'FALSE' value

  calcLat / calcLon
    The working coordinates used by the pipeline. For most records these
    match the original coordinates. For records with no original coordinates,
    these contain the county center point values.

  countyNameFromJoin
    The authoritative county name confirmed by spatial join against the
    Oklahoma counties boundary layer.

  countyFIPS
    The 5-digit federal FIPS code for the specimen's confirmed county.
    Used as a join key in ArcGIS and the Dashboard application.

  onTrackingList
    TRUE if the specimen matched an entry in the Oklahoma State Tracking
    List. FALSE if no match was found.

  State Rank / Global Rank / Federal Status
    Conservation ranking information from the Oklahoma State Tracking List.
    Blank for species not on the tracking list.


COUNTY SUMMARY SHAPEFILE
  Location: data/countySHP/countyDataOutput.shp

  This shapefile summarizes specimen data at the county level and is the
  data source for the choropleth map in the UCO Herbarium StoryMap and
  ArcGIS Online dashboard. It contains one row per Oklahoma county with
  the following fields:

  GEOID
    The 5-digit FIPS code uniquely identifying each county.

  NAME
    The county name.

  specCnt
    Total number of non-sensitive specimens recorded in that county.

  trackCnt
    Number of specimens in that county with a successful Oklahoma
    Tracking List match.

  rankS1
    Number of S1-ranked specimens in that county.
    S1 = Critically imperiled — highest conservation concern.

  rankS2
    Number of S2-ranked specimens in that county.
    S2 = Imperiled.

  rankS3
    Number of S3-ranked specimens in that county.
    S3 = Vulnerable.

  rankSH
    Number of SH-ranked specimens in that county.
    SH = Possibly extirpated from Oklahoma.

  Note: Counties with no specimens will show 0 in all count fields.
  Sensitive species records are excluded from all counts.

  This file is regenerated automatically every time the pipeline runs.
  No manual steps are required to update the county map data.


LOG FILES
  Location: logs/ subfolder

  countyMismatches.csv
    Records where the specimen's coordinates do not fall within the county
    listed in the data. These records are retained in the cleaned dataset
    but flagged here for your review. A mismatch may indicate a data entry
    error or a coordinate error in the original record.

  entriesNotInOK.csv
    Records whose coordinates fall completely outside Oklahoma. These have
    been removed from the cleaned dataset. Typically these are specimens
    collected in neighboring states or records with coordinate errors.

  unreferenceableSpecimens.csv
    Records with no coordinates and no county name that could not be
    georeferenced by any method. These have been removed from the cleaned
    dataset and require manual review. This file is only created if
    unreferenceable records are found.

  trackingListMatches.csv
    All specimen records that successfully matched an entry in the Oklahoma
    State Tracking List. Useful for reviewing which tracked species are
    represented in the UCO collection.

  excludedSensitiveSpecimens.csv
    Records removed from the public-facing dataset due to sensitive species
    status. Currently includes all Orchidaceae (orchid) records and
    Echinocactus texensis (Horse Crippler Cactus). Retained here for
    internal herbarium use only.


================================================================================

ADDING SPECIES TO THE SENSITIVE SPECIES LIST
--------------------------------------------------------------------------------

If additional species need to be excluded from the public-facing dataset in
the future, contact the pipeline administrator (Marc Wright) to update the
exclusion list in the script. The list is clearly marked near the top of the
file and can be updated by adding the exact scientific name.


================================================================================

WHAT TO DO IF SOMETHING GOES WRONG
--------------------------------------------------------------------------------

The pipeline will not change or delete your original CSUoccurrences.csv file.
If something goes wrong, simply run the pipeline again.

Common issues:

  "FileNotFoundError: CSUoccurrences.csv"
    The pipeline cannot find the data file. Make sure CSUoccurrences.csv is
    in the "data" subfolder and the filename is spelled exactly correctly.

  "FileNotFoundError: okCounties.geojson"
    The county boundary file is missing from the data folder. Do not delete
    or move this file.

  The pipeline runs but the cleaned file looks wrong
    Check the log files in the logs/ subfolder. The countyMismatches.csv
    and entriesNotInOK.csv files will show you which records had issues.

For any other issues, contact Marc Wright for support.
